A rule from the runner about this machine. If you drive an iOS or Android simulator, use the `agent-device` CLI, never the built-in simulator MCP tools, and run `agent-device help <command>` before guessing a flag. Leave no simulators behind: shut down every simulator you booted with `agent-device close --shutdown` (plain `close` leaves it running, at 1–2.5 GB each) and delete every one you created. If another session has claimed a device, it is theirs: create your own instead.
